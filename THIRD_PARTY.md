# Third-party dependencies and attribution

External source trees, robot assets, datasets and installed applications are
downloaded locally; they are not distributed in this repository. Their original
headers and licensing terms remain applicable.

| Dependency | Version/source | Use and upstream terms |
| --- | --- | --- |
| Flybrain | [evolutionary-behavior](https://github.com/dylankainth/flybrain/tree/97e02fb7c8d19fd5267c3fa9194f8001e08fb613) | Original neural class and sensory/readout reference; upstream README declares MIT. Commit and source checksum are in `upstream.json`. |
| Webots / Crazyflie assets | [R2025a](https://github.com/cyberbotics/webots/tree/R2025a/projects/robots/bitcraze/crazyflie) | Install Webots separately. Downloaded PROTO/meshes retain Cyberbotics' asset notices, including the [Webots asset license](https://cyberbotics.com/webots_assets_license). |
| Bitcraze velocity/altitude PID | [R2025a controller](https://github.com/cyberbotics/webots/blob/R2025a/projects/robots/bitcraze/crazyflie/controllers/crazyflie_py_wallfollowing/pid_controller.py) | MIT, Copyright 2023 Bitcraze AB; downloaded unchanged with header retained. |
| FlyWire / FAFB v783 | [Codex data downloads](https://codex.flywire.ai/api/download) | Connectivity, neurotransmitter predictions, cell types and side annotations. Consult the source's citation and data-use terms before redistributing data. |
| Shiu et al. reference dynamics | [Pinned model.py](https://github.com/philshiu/Drosophila_brain_model/blob/91bdd1e7dcf193f3e7ca5a8933497fcef63b7960/model.py) | Reference for voltage-based LIF equations and parameters. Python dependencies are installed with pip and retain their respective licenses.
Our small floor/probe/diagnostic textures are generated by our scripts.
# FlyVis bridge

The optional visual front end uses [FlyVis](https://github.com/TuragaLab/flyvis)
(Lappalainen et al., Nature 2024), pretrained model `flow/0000/000`.
Its source, weights, and dependencies retain their upstream licenses.

Spatial handoff maps, calibration scales, and the mapping/interface design are
adapted from [vib2810/fly-brain-zero-shot](https://github.com/vib2810/fly-brain-zero-shot),
commit `0c63ba5cdd123f8d38eea62deb574353f0ec2632`, Copyright (c) 2026 Vibhakar Mohta,
MIT. A copy of the license is in [docs/licenses/fly-brain-zero-shot.txt](docs/licenses/fly-brain-zero-shot.txt).
The root-ID ordering table is pinned to philshiu/Drosophila_brain_model commit
`91bdd1e7dcf193f3e7ca5a8933497fcef63b7960`. Setup verifies hashes and writes a
local provenance report; no third-party datasets or model weights are committed.
